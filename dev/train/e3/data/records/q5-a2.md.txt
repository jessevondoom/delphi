### red-team

> OPTION: Approve with amendments
> 
> Exempting non-executable presentation artifacts (documents, slide decks, diagrams, media) from the overhead of formal architectural specs is pragmatic, but introduces an evasion vector unless boundaries are deterministically enforced in code. "No Spec, No Build" for all software, scripts, and external coding guidance must remain absolute; artifact exemption must never become a backdoor for unreviewed code execution, payload smuggling, or silent memory poisoning.
> 
> Spec 070 should be approved with the following rulings on open decisions and amendments:
> 
> - **D-1 (Log Location):** Store the artifact prompt log strictly in daemon-managed, append-only audit storage (e.g., `.delphi/audit/artifact-prompts.jsonl`) outside any agent worktree or mutable workspace mount. Non-daemon processes must have zero write, append, or truncate capabilities.
> - **D-2 (External Project Spec Location):** Mandate `specs/external/<project>/` within Delphi's own governed repository. Storing external specs in target repositories breaks Delphi's deterministic review rubric, bypasses IFC taint-lattice verification, and circumvents operator ratification under `[REV-SEC-04]`.
> - **D-3 (Log `(system)` Entries):** System-initiated generation must be explicitly logged and tagged as `(system: <canonical-role>/<task-id>)`. Forbid collapsing system calls into operator prompts or omitting unprompted artifact creation; silent or unattributed generation in multi-agent loops is a major vector for hallucinated drift.
> 
> **Mandatory Amendments:**
> 1. **Payload & Script Sanitization:** The closed allow-list must enforce static-only serialization. The runtime must reject or strip executable content (e.g., active `<script>` tags in HTML, SVG event handlers/foreignObjects, and macro-enabled spreadsheet formats).
> 2. **Governed Path Confinement:** Enforce an invariant that artifact tools can never write to governed paths (`specs/`, `memory/`, `agents/`, `skills/`, `themes/`, or `.delphi/`).
> 
> ### Identified Risks
> 
> 1. **Active Payload Smuggling via Allowed Formats:** An agent or poisoned dependency crafts an HTML, SVG, or office file containing malicious active content.
>    - *Failure Scenario:* An operator opens a generated HTML report or SVG diagram that executes script payloads or leverages client exploits.
>    - *Remediation:* Enforce deterministic AST-level sanitization at write time; refuse raw script blocks.
> 2. **Audit Log Evasion via Workspace Co-location:** Placing the prompt log in user- or agent-accessible workspace paths.
>    - *Failure Scenario:* A misbehaving agent truncates or mutates prompt logs to mask unapproved artifact generations.
>    - *Remediation:* Enforce D-1: the log is managed exclusively by `delphi-core` daemon IPC.
> 3. **Ghost Artifact Churn (Autonomous Loops):** Autonomous subagents repeatedly generate artifact files without explicit operator intent.
>    - *Failure Scenario:* Context overflow and disk bloat via runaway autonomous runs.
>    - *Remediation:* Enforce D-3 logging and bind artifact generation quotas to the originating task contract.
