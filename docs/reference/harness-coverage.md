# Harness coverage

Generated by `delphi docs coverage` from `crates/delphi-engine/coverage/*.cov`; do not edit by hand. Every flag and subcommand of the subscription CLIs has exactly one disposition (`specs/043`, `specs/044`). `used`: Delphi passes it. `planned`: in the named slice. `read-only`: Delphi may run it to learn something. `operator-only`: it changes the operator's global state or account, so the operator types it. `refused`: Delphi never uses it. `n/a`: not relevant to a headless span. A `group` row covers everything beneath its path.
