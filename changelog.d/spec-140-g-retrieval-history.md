- **Retrieval quality is kept over time** (spec 140 G): every `delphi kb eval run` (and a scheduled run every `[retrieval] eval_every_days`, 7 by default, made while the daemon is idle and spending no tokens) adds its numbers to `local/eval/history.jsonl`, a ledger that is only appended to and survives a reindex, a new golden set and pruned run files. `delphi kb eval history` shows each series (one set version on one path) with the change from run to run and a trend; `delphi kb health` shows the newest run against the median of the five before it. The view `local/knowledge/retrieval-quality.md` is rebuilt after each run, so an agent's search for retrieval quality finds it. A noticeable change (0.03 in recall@10 or nDCG@10, ten points of the vector leg, or 1.5 times the p95 latency) leaves one provisional note for the operator to review. `--trigger before|after` (or a label of `before` or `after`) marks the runs of a retrieval change. A run started by an agent seat is not added to the history.
