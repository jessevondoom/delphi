- **Routing can send a single model call to a subscription CLI** (spec 143, slice A): a new key, `[routing] single_call_harness` (`"auto"`, `"on"`, `"off"`; default `"auto"`). Topic and search pages, their validator, summaries, the fact judge, decision briefs and the scout's calls each send one prompt and read one answer; under `"auto"` an allowed `claude` harness is chosen for them only when no other allowed endpoint can serve, and only once its subscription token is named in the new key `[bridge.claude] credential` (a credential reference such as `"keychain:bridge-claude"`, never the token), so an install with an API endpoint, or with no token named, behaves as before. `agy` is never chosen, and `codex` and `copilot` not yet. A single call that fails now has a cause from a closed list (`no_route`, `budget`, `quota`, `timeout`, `harness_tool`, `launch`, `empty`, `provider`), and a background job's notice carries it. `delphi doctor` says which harness serves single calls, or what is missing. Not yet built: the call itself (slice B); until it is, naming a token makes these jobs raise a `launch` notice.
