- **A single model call can run through the `claude` CLI** (spec 143, slice B, first part): when routing gives a single call to a `claude` harness, the daemon runs the CLI once, for one prompt and one answer, with its tools off. Each call gets a home built empty for it (never your own configuration home, and never a place with a `CLAUDE.md`, `AGENTS.md` or `.claude` anywhere above it), an environment of a few plain variables and the subscription token named in `[bridge.claude] credential`, and no `ANTHROPIC_API_KEY`; the prompt goes to standard input. A tool request ends the call, the answer is redacted before anything reads it, and the home is removed afterwards. A new key, `[routing] single_call_harness_timeout_secs` (default 180), stops a call that runs too long. Each call spends your own subscription quota. Not yet built, so do not leave it running unattended: the limits on how many calls run (the ledger, the rolling window and the daily cap), the pause while you are working, the yield to Councils and agents, and the usage record. There is no OS sandbox behind the call. Checked against `claude` 2.1.332; not verified on other versions.
