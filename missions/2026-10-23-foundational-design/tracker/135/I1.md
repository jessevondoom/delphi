Built 2026-11-23 (draft pull request, not merged). `forge_ready.rs`: reads the pull request with `gh pr view`, polls `gh run list --branch <head>` every 15 s (at most `--wait`, default 3 min) until a run of the head commit exists (none: not marked ready, exit 1), runs `gh pr ready`, then waits as long for a new run of that head; with none it toggles draft and ready once and says so. Processes start through `finisher_gates::SystemRunner` (no new spawn site). Tests with a fake `gh` and a counting sleep (AC-44, AC-45, the refusals). Help, the generated reference, and one line each in `skills/git-pr-packaging/SKILL.md` (step 9) and `skills/agentic-ci-cd-strategy/SKILL.md` (A2).

Not verified: a run against GitHub (the real event timing of #888 and #897 was not reproduced), and that `gh run list` lists the `ready_for_review` run under the head branch within the default bound.
