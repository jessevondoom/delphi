Built 2026-11-25 (local branch `build/142-a`, not pushed).

**The cap.** `[library] text_cache_max_mib`, default 1024, at least 16; with the key absent and `private_text_max_mib` set, that value is the cap (the config test covers 20). It bounds `Library::cached()`: text research kept privately (`kept_privately`), every capture whose record says `rights: held`, and every capture a host handed over, `raw` and text over all kept versions. Text under an open licence is not in it.

**The use ledger.** `Library::note_use` records a use in memory and `library/cache-use.json` is written at most once a minute, on a thread of its own. A use is: a search that returns a passage of the source (`retrieval::search`), a page gather (`topic_gather::sort_hits`), an open (`delphi sources show`, which writes before it ends, and the app's `library.source`), and a revisit (`Library::store`).

**Eviction** (`Library::cap_text_cache`, called by `Library::store` after every capture when the library was built `with_text_cache`; the research keep step sets it). Least recently used first, a never-used capture ordered by when it was captured, and among equals an unconfirmed never-used host capture first. Two passes: the `raw` files, then the text; the capture just kept last. An evicted source keeps its record with its digests and `evicted`, its excerpts, pinned excerpts, claims and anchors (slice E). Never evicted: a capture the operator added (`captured_by: operator`) and a source whose record says `pinned: true` (the command that sets it is slice D2). `Library::cache_admits_host(incoming, max, now)` is the rule for a host's capture: `cache full: pin less or raise the cap`, and nothing evicted, when room could only come from text used in the last seven days; a host capture stored all the same gives up its own bodies.

Tests: AC-11 (20 MiB under a 16 MiB cap, the order of what went, what stays of the evicted source), AC-12 (used yesterday outlives used a month ago; the old key), AC-29 without its first clause (below), `the_cache_is_never_over_its_cap_after_a_capture`, the ledger's once-a-minute write, a search hit as a use. Held and host captures do not exist until slices B and C, so those tests write such captures to disk as fixtures.

**Run on a copy of the operator's library, 2026-11-25** (`cp -cR ~/.delphi/library` into this build's scratch directory, every command with `--home`): `sources list` shows the 94 sources (86 fetched pointers, one at version 2, and 8 host-reported private pointers), `claims list` the 6 claims; `sources verify` reports `0 capture(s) checked, 0 differ` and exits 0; `sources show` and `sources private list` read as before. The only file written was `library/cache-use.json`, by the open in `sources show`; every other file was byte for byte what it was. No source has a `capture.json` until its page is read again.

Not done here, and for Architect: (1) AC-29's first clause (three sessions and the hourly limit for all sessions) needs `capture_source` and its limits, which are slice C's; D1 builds the cache rule only. (2) AC-11's last clause is read as: a capture gathered today keeps its **text** while an unused one remains; under the two passes of §2.4 item 3 its `raw` can go before an unused capture's text. (3) An open in the app writes the ledger, so `library.source` is no longer a read that leaves the home byte for byte unchanged; the test that says so (`every_encyclopedia_read_leaves_the_workspace_byte_identical_and_calls_no_model`) already fails on this branch for a reason of spec 139's and could not be run to its end.
