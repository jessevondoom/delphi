| 120 | K6 | the red-team fixtures and the end-to-end check | built and merged (#743) as far as an agent can take it: **the fixtures** are tests. A document that tries to cause a request: a source, a claim, a topic page and a heading whose text is a request, an instruction and a button are read by every read the app has, and nothing is asked, counted or started; a request carrying a document's words in place of an id, or beside one, is refused before it is counted; the window draws the same text as text, with no button, script or link to a method made from it (`redteam_a_document_that_tries_to_cause_a_request_causes_none`, and `app/test/request.test.tsx`). A second program on the app socket and a replayed handshake: against the daemon's real server and engine, a request sent before a handshake ends the connection, a signature by another key or a recorded hello sent again is refused and recorded, and none disputes anything (`redteam_a_paired_key_asks_end_to_end_and_a_stranger_or_a_replay_asks_for_nothing`). **The end-to-end check** is that same test for the daemon's half (a ticket, pairing, a session on the key alone, a request, its event arriving on the session, revocation closing it) and the bridge's tests for the app's half, each against the other side's stand-in. **Not done: the check on a machine** (AC-1: pair from a terminal, quit, start from the Finder, ask a follow-up, revoke). A ticket is given only to a client at a terminal and an agent has none, by design; `delphi app` does not start the app until its process-start site is listed (K2's own pull request); and the window's buttons were not clicked in the built app. `app/README.md` has the five steps for a person, with `pair_probe` (which can now ask, `DELPHI_PROBE_ASK`) or the window. **Found for the red-team:** a connection that sends anything but a handshake first is closed without an `app.refused` record (only a wrong ticket, signature or key is recorded), so a program probing the socket that way is not counted toward the lockout; the anchor of a heading reaches a research run's note as the operator's words (at most 80 lowercase letters, digits and hyphens); the hour's count of requests is forgotten when the daemon restarts |
