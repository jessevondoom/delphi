| M3 | the relay-stream replacement; flips Relay and Mail | 8-12 | built, draft PR (the operator asked for it on 2026-11-12). The daemon filters every event before a relay client is sent it (`Hub::set_relay_filter`, installed by `private_read::install_relay_filter` when an engine is built): for a task whose mark is live, or cannot be read, or whose mission is marked, the agent-written fields of `approval.requested` (`summary`, `payload`, `pattern`), `decisions.review_requested` (each `summary` and `rationale`), `task.completed` (`reason`) and `task.failed` (`error`) become one fixed phrase, and the card carries `withheld: true`; ids, tier, tool, payload hash, status and counts stay. Mail is the relay's SMTP transport, so the same stream covers it. A task that read nothing private is sent exactly what it always was. The relay's `approval.list` agrees with its stream, and `approval.relay_resolve` refuses an allow for a withheld card (a deny stays open); the relay shows only Deny for it. The decision goes through `egress::check` with a record shaped from the mark (unreadable reads as private), so Relay and Mail are `Wired::Yes` (rows name `private_read.rs`); Connector and Outbound stay `Unaudited` until M2. NOT built: any agent-reachable clear (OD-4's delegated form), the Connector and Outbound behaviour (M2), a mark from the page readers. What marks a task today: only the host's `search_kb` marks the host session (M1); Delphi's own tasks read no private entry through a marking reader yet, so on a real install the filter changes nothing until a reader marks. Nothing ran against a real relay or mailbox. |
