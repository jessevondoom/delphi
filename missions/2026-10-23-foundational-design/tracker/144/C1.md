Built 2026-11-27 on `build/144-c1` (pushed, no pull request; the lead integrates). Spec 144 §2.5, §2.6 items 2-3, AC-11, AC-12.

**This slice changes what retrieval indexes.** Every research topic that has a claim with an anchored quote now has a second untrusted document in zone `research`, `research/topics/<topic-id>/evidence-pack.md`, at `external_untrusted`. Searches that admit held text (`include_held`) admit packs too; a search that admits neither sees no pack. Ranking, chunking and fusion are unchanged. The golden set of 140 has to be run again once packs exist on a real install (§2.8 item 1.4).

**The pack** (`crates/delphi-engine/src/evidence_pack.rs`).
- Written when a research run ends `done` or `partial` (the daemon's `on_end`, after the record), and when a host's `record_research` returns. No model call.
- For each claim the topic's record lists, at each active anchor: the quote, the stored text around it (`library::claims::context_of`, 200 characters each side), the source id, the sha256 of the source's stored `source.md`, and an empty `support:` line for C2.
- An anchor whose quote is not found letter for letter in its source's stored text is left out and counted (`left_out` in the frontmatter).
- A topic with no anchored claim keeps no pack; an earlier one is removed.
- Markdown with frontmatter (`kind: evidence_pack`, `topic`, `run`, `source_type: external_untrusted`). One `##` section per claim at one source, so a chunk holds the claim, its source and its passage. Each passage line is quoted with `> `, so page text cannot make a heading.
- Written through `research_record::write_atomic` (now `pub(crate)`), so the agy guard knows it as Delphi's own write.

**The label** (`evidence_pack::label_of`, called by `Labeller::path`).
- The join of every source the topic's runs read (the record's `pages` and `private_sources`), quoted or not, and every source its claims are anchored to, with the record's own private flag. All five marks.
- Computed from the records every time. Nothing reads the pack's own frontmatter as its label.
- Untraceable is every mark: no workspace known, a record that cannot be read, no source to trace, or a source whose record cannot be read.

**Exits.** `held_text::SENDERS` has the pack. The listed call is `crate::evidence_pack::label_of(` in `label.rs`, and the proof test is `a_bundle_export_or_push_that_carries_a_pack_of_a_held_or_private_source_is_refused`. `label::of_files`, which every `egress::check_output` exit uses, now labels a file with the pack's label in three cases:
- the file is the pack itself, by its path in the workspace;
- the file's frontmatter says `kind: evidence_pack` and names a topic (this only adds marks);
- the file carries a run of more than 300 characters of any pack of the workspace or its projects.

`held_text::check_files` then applies `body_may_leave`. The test sends packs to bundle, page export, Xenia, a public repository and a document. A pack with one quotation of a held source within the bound may leave (the pack's `«»` quote marks cut its run). With three quotations it is past the cap of a tenth of the source and is refused. So is a pack from a run that read a private source, even one it does not quote, and so are copies of it outside the workspace, with frontmatter or without. A pack of open sources passes.

`private_read::READS` lists `evidence_pack.rs`: it reads `source.md`, and it is withheld from every search when a run read a private source. The proof test is the §2.6 item 3 test below.

**Search** (`kb.rs`, `research_index.rs`).
- The index lists a pack only while it is not withheld.
- Every search computes the pack's label again from the records before it returns any row of it. The workspace comes from the index's own path, `<ws>/local/state.db`. An index elsewhere or in memory cannot trace a pack, so it returns none.
- Withheld means `library_private` or `personal`. A run that read a private source therefore never reaches an agent, and a source made private is out at the very next search, before any refresh.
- Otherwise the hit is labelled `evidence pack · not validated`, at `external_untrusted`, status noted, with the label just computed as its `marks`.

**`delphi research pack <topic-id> | --all`** writes packs for earlier runs from their records and the stored text (`--json` too). It is refused inside an agent seat. It is in the CMDS table, the usage text and the regenerated `docs/reference/cli.md` and `delphi.1`.

**Tests** (`evidence_pack_tests.rs`):
- `a_finished_run_writes_a_labelled_indexed_pack_of_its_anchored_claims_and_a_reclassified_source_reclassifies_it` (AC-11, reclassification);
- `no_search_returns_a_pack_from_a_run_that_read_a_private_source_or_one_that_cannot_be_traced` (§2.6 item 3);
- `a_bundle_export_or_push_that_carries_a_pack_of_a_held_or_private_source_is_refused` (AC-12);
- `packs_are_written_for_earlier_runs_from_their_records` (AC-11, `--all`);
- `a_pack_is_known_by_its_path_and_its_own_frontmatter_names_its_topic`.

**Decisions where the spec was silent.**
- *Admission:* until 145 A, a pack is admitted with held text (`include_held`), because it quotes held text and §2.6 item 1 keeps 142 B's rule. A role that acts sees packs only when it asks for held text.
- *Which marks hide a pack:* "private" means `library_private` or `personal`. `internal`, `confidential` and `text_held` packs are returned, carrying their marks.
- *What the label includes:* the sources the claims are anchored to, as well as those the record lists, which can only add marks.
- *Text hash:* the sha256 of the stored text as it is when the pack is written, so C2 can tell when the text changed.
- *Scope of a pack:* one pack per topic, over all its runs' claims, rewritten whole at each run's end.
- *Project topics:* a pack under a registered project is written and labelled at exits, but only the workspace's own topics are indexed in zone `research`, as answers are today.

- §2.7 item 4 (a page's label joins its packs) is slice B's. It will hold once a page's sidecar names a pack's path, because `Labeller::path` now labels one.
