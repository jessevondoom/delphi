- **(b) Spec Self-Approval Gate:** **Agree and refine for bounded L2 bug fixes.** Only the **operator** can approve a spec ([003-collaboration-and-council.md](../../../../specs/003-collaboration-and-council.md#L53)); `delphi-core` blocks agents from writing `status: approved` or `approved_sections`, and verifies at `Spec-Gate` ([#L73](../../../../specs/003-collaboration-and-council.md#L73)) and Merge Gate 3 ([#L65](../../../../specs/003-collaboration-and-council.md#L65)) that `(zone="team", path="specs/NNN-*.md", content_blake3)` has an $L_5$ operator entry in `local/ratified.lock` and the provenance index ([001-governance-and-manifests.md](../../../../specs/001-governance-and-manifests.md#L217)). For spec-less L2 bug fixes ([#L38](../../../../specs/003-collaboration-and-council.md#L38)), permit `spec_exempt: l2_bounded` only when the diff is deterministically bounded ($\le 2$ files, $\le 100$ changed lines, zero `host_exec_paths` or dependency edits) and operator-approved at worktree creation and Merge Gate 5.
- **(c) Step 2 Go/No-Go Scope:** **Agree with Strategist.** Scope Step 2 ([roadmap.md](../../../../missions/2026-10-23-foundational-design/roadmap.md#L54)) to `L1` and **read-only `L2`** (1–2 node read-only discovery, spec drafting, and audit chains across `orchestrator`, `architect`, `red-team`, `strategist`, with writes restricted to `missions/**` and `team/specs/**` drafts). Defer worktree-mutating `L2`/`L3` (`Builder`, sandbox, Merge Gates, Attempts 2–3) to Step 3.
- **(d) Redaction vs Signed Reasoning:** **Distinguish provider-redacted vs Delphi-redacted vs GC compaction:**

Drop `provider_meta.signature` and convert the block to a tag-escaped `<prior_reasoning_note>` `assistant` text block; if an active Anthropic tool loop rejects an unsigned assistant `tool_use` turn when `thinking` is enabled, send that single continuation call with `thinking` disabled/omitted.
  3. *30-day `delphi gc` compaction ([005-console-and-narrator-tui.md](../../../../specs/005-console-and-narrator-tui.md#L116)):* Never compact open missions; on closed missions >30 days old, write a new segment replacing both `thought` and `signature` with `{compacted: true, thought_blake3}`.
